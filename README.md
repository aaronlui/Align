# Align

轻量的 macOS 菜单栏工具，将当前窗口居中，保持窗口大小。支持 macOS 13 及以上版本的 Apple 芯片和 Intel Mac，无第三方依赖。

## 构建

需要支持 Swift 6 的 Xcode 或 Command Line Tools。在项目根目录运行：

```sh
bash scripts/build-app.sh
```

生成 `dist/Align.app`，包含 arm64 和 x86_64 两种架构。将应用拖入“应用程序”后打开。

## 使用

1. 首次使用，在“系统设置 → 隐私与安全性 → 辅助功能”中添加并开启 Align。未授权时，也可通过菜单中的“辅助功能设置…”进入。
2. 切换到目标窗口，按 **⌃⇧C（Control + Shift + C）** 居中，或点击菜单栏中的“居中”。
3. 勾选“开机自启动”，在后续登录时自动启动；取消勾选即可关闭。若系统需要批准，应用会打开登录项设置，批准后菜单才会显示勾选。
4. 使用菜单中的“退出”关闭应用。

Align 仅显示菜单栏图标，不显示 Dock 图标。

## 窗口行为

- 在屏幕可用区域内居中，避开菜单栏与 Dock。
- 窗口跨屏时，选择重叠面积最大的屏幕；窗口完全离屏时，选择距窗口中心最近的屏幕。
- 仅修改位置，不缩放窗口。大于屏幕的窗口居中后仍可能超出屏幕边界。
- 全屏、最小化、不可移动或不支持辅助功能的窗口无法居中。
- 快捷键注册失败时会提示，仍可使用菜单操作。

## 测试

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-module-cache" swift test --disable-sandbox
```

现有 9 项测试覆盖居中坐标、多屏坐标转换、跨屏选择、离屏恢复、超大窗口和坐标取整。辅助功能授权、全局快捷键及实际登录自启动需要在图形会话中手动验证。

## 签名

构建脚本使用 ad-hoc 签名，尚未通过 Apple 公证。macOS 可能限制首次打开；请确认应用来源后，按系统提示处理。重新构建后，系统也可能要求重新开启辅助功能权限。
